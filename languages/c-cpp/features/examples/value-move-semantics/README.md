# 值语义与移动语义

## 目标

这个例子用带日志的 `Buffer` 展示对象在返回、传参和放入容器时如何拷贝或移动。值语义让每个对象拥有自己的数据，移动语义让临时对象把资源转交出去，减少不必要的深拷贝。

## 运行

```bash
c++ -std=c++23 main.cpp -o /tmp/cpp-feature-example && /tmp/cpp-feature-example
```

## 观察点

- `copy` 表示创建了一份独立数据，修改其中一个不会影响另一个。
- `move` 表示资源所有权转移，常见于返回值、临时对象和 `std::move`。
- 容器扩容时可能移动已有元素；给 `std::vector` 预留容量可以减少这类搬迁。
