# throwable-recovery

## 目标

理解 PHP 的请求生命周期和 `Throwable` 错误模型。例子用命令行模拟三个请求：正常请求、业务规则失败、类型错误。外层处理函数像框架入口一样负责调用业务、捕获错误、转换响应并执行清理。

## 运行

```bash
php main.php
```

## 观察点

- 每个请求都重新进入 `handleRequest`，局部变量在本次处理结束后就不再被依赖。
- `DomainException` 表示可以给用户解释的业务失败；`TypeError` 属于程序错误，例子把它转换成通用 500 响应。
- `finally` 无论成功或失败都会执行，适合关闭文件、释放锁或归还连接等清理动作。
