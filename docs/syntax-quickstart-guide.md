# 基础语法速览写作规范

本规范用于新增 `languages/<language>/syntax/`。读者假设是“已经有其他编程语言经验，但第一次系统接触这门语言”的人。

## 目录结构

每门语言至少包含：

```text
languages/<language>/
  README.md
  syntax/
    README.md
    examples/
      syntax-tour/
        README.md
        <source-file>
```

## `syntax/README.md` 要求

- 标题格式：`# <Language> 基础语法速览`
- 必须包含以下二级标题：
  - `## 读者定位`
  - `## 运行方式`
  - `## 语法速览`
  - `## 类型与值`
  - `## 控制流`
  - `## 函数与模块`
  - `## 集合与数据建模`
  - `## 错误处理`
  - `## 惯用写法`
  - `## 可运行示例`
  - `## 学习检查`
- 内容要面向有编程经验的读者，重点解释“这门语言和你可能熟悉的语言相比，语法心智模型有什么不同”。
- 不要堆关键字列表。每个小节都要说明语法背后的取舍、常见误解和迁移提示。

## 示例要求

- 至少 1 个 `syntax-tour` 可运行示例。
- 示例 README 必须包含：
  - `## 目标`
  - `## 覆盖语法`
  - `## 运行`
  - `## 观察点`
  - `## 修改练习`
  - 一个 `bash` 代码块，第一条非注释命令必须可复制运行。
- 示例源码应覆盖该语言的基础语法组合：
  - 变量/常量
  - 基础类型与字符串
  - 条件与循环
  - 函数
  - 集合
  - 简单数据建模
  - 错误处理或缺失值处理
  - 模块/命名空间/包的最小认知
- 示例优先使用标准库，不新增第三方依赖。

## 根 README 链接

每门语言的 `languages/<language>/README.md` 应在案例索引附近链接到：

```markdown
- [基础语法速览](syntax/)：面向已有编程经验读者的语法快速迁移。
```
